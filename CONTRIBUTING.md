# Contributing

Thanks for contributing to Fake ID Screening.

## Safety and privacy

This is a prototype screening system. Detection results are signals for human review, not authoritative determinations of document authenticity.

Never commit real identity documents, live photos, personal information, credentials, or production database data.

## Development

- Keep input validation and safe file handling intact when modifying upload flows.
- Add tests for API changes and validation rules.
- Keep offline demo behavior usable without requiring a deployed backend.
- Document changes that affect the mobile capture flow or screening API.

## Pull requests

Include a concise description, tests performed, and any security/privacy considerations. For UI changes, include screenshots or a short demo description.
