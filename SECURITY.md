# Security Policy

## Scope

This repository is a prototype identity-document screening system. Do not submit real identity documents, live photos, student records, credentials, or production database exports to public issues or pull requests.

## Reporting a vulnerability

Report vulnerabilities privately through the maintainer's GitHub profile with reproduction steps and impact details.

## Sensitive data

Use environment variables for database credentials, API keys, and JWT secrets. Treat screening results as signals for human review, not authoritative identity determinations.
